CÓMO SUBIR LA PÁGINA A GITHUB
=============================

QUÉ HAY EN ESTA CARPETA
- web/             -> LA PÁGINA. Es lo ÚNICO que se sube a GitHub.
- video-original/  -> tu video de postulación (94 MB). NO lo subas: GitHub rechaza
                      archivos de más de 100 MB y avisa con los de más de 50 MB.
                      Además, la página ya usa el video de Drive.
- material/        -> capturas de Instagram, tu foto original y el logo de Fanz
                      (en "no-usar"). NO se sube.
- .claude/         -> configuración para previsualizar la página. NO se sube.

PASOS (GitHub Pages, gratis)
1. Entrá a github.com > New repository.
   Nombre: ramiro-carugati (o el que quieras). Marcá "Public" > Create repository.
2. Hacé clic en "uploading an existing file".
3. Abrí la carpeta web, seleccioná TODO lo que hay ADENTRO
   (index.html, styles.css, main.js, scenes.js y la carpeta assets) y arrastralo.
   IMPORTANTE: arrastrá el contenido, no la carpeta "web" entera.
   index.html tiene que quedar en la raíz del repositorio.
4. Abajo, "Commit changes".
5. Settings > Pages > Source: "Deploy from a branch" > Branch: main, carpeta / (root) > Save.
6. En 1 o 2 minutos la página queda en:
   https://TU-USUARIO.github.io/ramiro-carugati/

SI UNA FOTO NO APARECE
- Fijate que se haya subido la carpeta assets/img con las 12 imágenes .webp.
- GitHub distingue mayúsculas de minúsculas: no renombres los archivos.

ARCHIVOS QUE PODÉS IGNORAR
- _headers y .htaccess sirven para Netlify y Hostinger. En GitHub no hacen nada
  y no molestan.
- Los archivos que empiezan con punto (.htaccess, .nojekyll) a veces no se suben
  al arrastrar. No pasa nada: la página funciona igual.

ANTES DE COMPARTIR EL LINK
- Abrí el video de Drive en una ventana de incógnito y confirmá que se ve sin
  iniciar sesión.
- Abrí la página desde el celular.
